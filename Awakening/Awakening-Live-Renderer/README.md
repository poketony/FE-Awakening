# FE 각성 메시지 실시간 검수기

Fire Emblem Awakening 렌더링 규칙과 필요한 에셋을 자체 포함해 브라우저 Canvas에서 사용하는 스탠드얼론 로컬 도구입니다. Java, 별도 패키지 설치, 원본 에디터 폴더가 필요하지 않습니다.

## 실행

1. `Awakening` 폴더 바로 아래의 `Awakening-Live-Renderer.bat` 또는 이 폴더의 `start.bat`을 더블클릭합니다.
2. 열린 브라우저에서 **번역 폴더 열기**로 `Messages (K)` 같은 검수 폴더를 지정합니다.
3. **일본어 폴더 열기**로 대응하는 `Messages (J)` 폴더를 지정합니다.
4. 왼쪽에서 파일과 메시지 키를 선택하고 가운데 텍스트를 수정합니다. 렌더 화면은 입력 즉시 갱신됩니다.
5. **저장** 또는 `Ctrl+S`를 누릅니다.

브라우저의 폴더/파일 쓰기 API가 필요하므로 최신 Microsoft Edge 또는 Chrome을 권장합니다. `index.html`을 직접 더블클릭하지 말고 반드시 `start.bat`으로 실행하세요. 서버를 끄려면 함께 열린 명령 창에서 `Ctrl+C`를 누릅니다.

`assets/awakening`에 폰트, UI, 얼굴, 머리 및 렌더링 메타데이터가 포함되어 있습니다. 실행 서버는 이 도구 폴더만 읽을 수 있으며 저장소의 다른 폴더나 기존 Java 에디터를 참조하지 않습니다.

선택한 번역/일본어 폴더와 마지막으로 열었던 번역 파일은 브라우저에 저장됩니다. 다음 실행 때 권한이 유지되어 있으면 자동으로 복원되며, 권한이 만료된 경우에는 **폴더 다시 열기** 버튼을 한 번 눌러 같은 경로를 재허용하면 됩니다.

상단의 **본편 / DLC** 버튼은 서로 독립된 작업 경로를 사용합니다. 각 모드에서 번역 폴더와 일본어 폴더를 한 번씩 지정하면 이후에는 모드 버튼만 눌러 두 경로를 함께 전환할 수 있으며, 마지막으로 사용한 모드와 모드별 마지막 번역 파일도 기억합니다. 기존에 저장되어 있던 경로는 본편 모드에 그대로 사용됩니다.

상단의 **주인공 이름**과 **성별**도 브라우저에 기억됩니다. 이름은 `$Nu` 자리에 표시되고, 성별은 `$G남성 문구,여성 문구|` 분기와 기본 마이유니 초상에 함께 적용됩니다.

**FILES**와 **MESSAGES** 제목 옆의 `‹` 버튼으로 각 사이드 패널을 접을 수 있습니다. 접힌 세로 탭의 `›` 버튼을 누르면 다시 열리며, 접힘 상태는 다음 실행에도 유지됩니다. 두 패널을 모두 접으면 확보된 너비가 번역·일본어 스크립트 편집 영역에 사용됩니다.

FILES의 **파일 정렬**에서 **이름순 / 최근 수정순**을 선택할 수 있습니다. 최근 수정순은 실제 파일 수정 시각이 최신인 파일부터 표시하고 목록에 수정 시각도 함께 보여 줍니다. 선택한 정렬 방식은 다음 실행에도 유지되며, `Alt+←/→` 파일 이동 역시 현재 화면의 정렬 순서를 따릅니다.

## 검수 상태와 단축키

각 메시지는 **미검수 / 확인 완료 / 수정 필요 / 보류** 상태를 가질 수 있습니다. 상태는 원본 텍스트가 아니라 브라우저에 본편과 DLC를 구분해 저장됩니다. MESSAGES의 상태 필터로 원하는 항목만 볼 수 있고, FILES에는 파일별 완료·수정 필요·보류 개수가 표시됩니다.

폴더를 열면 전체 파일의 검수 대상 항목을 백그라운드에서 계산해 FILES 상단에 전체 대사·파일 진행률을 표시합니다. 파일 안의 검수 대상이 모두 **확인 완료**가 되면 해당 파일이 초록색 **검수 완료**로 바뀝니다. 키 끝이 `_PCM2`, `_PCM3`, `_PCF2`, `_PCF3`인 항목은 목록에서 **진행도 제외**로 표시되며 파일 완료와 전체 진행률 계산에 포함되지 않습니다.

- `Ctrl+Enter`: 현재 항목을 확인 완료로 표시하고 다음 보이는 항목으로 이동
- `F3`: 현재 항목을 확인 완료로 표시하고 다음 검수 대상으로 이동
- `F2`: 현재 항목을 수정 필요로 표시
- `Alt+↑` / `Alt+↓`: 이전·다음 메시지
- `Alt+←` / `Alt+→`: 이전·다음 파일
- `Ctrl+←` / `Ctrl+→`: 이전·다음 회화 화면
- `Ctrl+S`: 현재 파일 저장
- `F8`: 수정 편의 모드 켜기/끄기

**수정 편의 모드**에서는 FILES, MESSAGES, 게임 화면, 일본어 칸과 진단 영역을 숨기고 번역 스크립트 편집기를 창 전체로 넓힙니다. 현재 커서와 선택 영역은 모드를 전환해도 유지됩니다.

번역·일본어 스크립트는 `$k\n`과 `$k$p` 경계를 기준으로 대사 덩어리마다 화면에서만 줄을 나눠 표시합니다. 이 표시용 개행은 입력값에서 제거한 뒤 원래 한 줄 형식으로 문서에 반영되므로 저장 파일의 줄바꿈이나 제어코드는 바뀌지 않습니다.

## 파일 보존 방식

- 메시지 키와 콜론 오른쪽 값만 편집합니다.
- 선택 항목 외의 텍스트, 빈 줄, CRLF/LF, UTF-8 BOM 유무는 바꾸지 않습니다.
- 저장은 다운로드 사본이 아니라 열었던 원본 파일에 기록합니다. 브라우저가 쓰기 권한을 한 번 더 물을 수 있습니다.

## 일본어 자동 매칭

다음 순서로 일본어 파일을 찾습니다.

1. 선택 폴더 안의 동일한 상대 경로
2. 동일한 파일명
3. 첫 줄의 `MESS_ARCHIVE_...` 식별자

자동 매칭되지 않는 파일은 **일본어 파일 지정**으로 직접 고를 수 있습니다. 메시지는 동일한 키로 대응시킵니다.

## 렌더 범위

`$t0`, `$t1`, `$Wm`, `$Ws`, `$E`, `$Wd`, `$Nu`, `$G`, `$c`, `\\n`, `$k$p`, `$k\\n`을 화면 상태에 반영합니다. 음성·BGM·대기처럼 정지 화면에 영향이 없는 코드는 제거하고 넘어갑니다. 얼굴/감정/글꼴 에셋이 없으면 해당 레이어만 투명하게 건너뛰며 **렌더 진단**에 경로를 표시합니다.
