# 일본어 인게임 폰트 프로필

라이브 렌더러의 오른쪽 일본어 인게임 화면(`jaCanvas`)은 한국어 화면과 별도의 글리프 테이블/폰트 아틀라스를 사용할 수 있습니다.

다음 파일을 배치하면 일본어 프로필이 자동으로 활성화됩니다.

```text
assets/awakening/
├─ bin/
│  └─ chars.bin                 # 기존 한국어 글리프 테이블 (변경 금지)
├─ img/
│  ├─ Awakening_0.png           # 기존 한국어 아틀라스 (변경 금지)
│  └─ Awakening_1.png           # 기존 한국어 아틀라스 (변경 금지)
└─ ja/
   ├─ bin/
   │  └─ chars.bin              # 일본어판 BFNT에서 추출한 글리프 테이블
   └─ img/
      ├─ Awakening_0.png         # 일본어판 폰트 atlas 0
      └─ Awakening_1.png         # 일본어판 폰트 atlas 1
```

일본어 파일 셋이 완전하게 존재하면 `jaCanvas`에서만 해당 프로필을 사용합니다. 셋 중 하나라도 없으면 기존 한국어 폰트 프로필로 폴백하며 라이브 렌더러 자체는 계속 동작합니다.

## 글자 코드 매핑

이 렌더러의 `chars.bin`은 BFNT에서 추출한 16바이트 글리프 엔트리를 읽습니다. 첫 2바이트 글자 값을 little-endian `uint16`으로 읽어 해당 프로필의 글리프 맵을 구성하므로, 한국어와 일본어는 서로 독립된 `chars.bin` 매핑을 가집니다. HTML/CSS 폰트나 편집기 UI의 브라우저 폰트는 이 프로필과 무관합니다.

## 지원회화 사이트와의 분리

`FE-Support-Archive`는 라이브 렌더러의 기존 한국어 `bin/chars.bin`, `img/Awakening_0.png`, `img/Awakening_1.png`를 명시적으로 복사해 사용합니다. 따라서 위 기존 세 파일을 그대로 유지하고 일본어 파일을 `ja/` 아래에 추가하는 한 지원회화 사이트의 렌더링 폰트에는 영향을 주지 않습니다.
