# 파이어 엠블렘 if DLC 번역 노하우 누적 노트

> 이 문서는 고정 규칙집이 아니라 계속 갱신하는 실전 노하우 기록이다.
> 번역 전에 읽고, 사용자 피드백이나 정발판 관찰에서 새 경향을 얻을 때마다 즉시 추가한다.

---

# 0. 최상위 대원칙 ― 가장 중요

## “지원회화를 참고한다”의 정확한 뜻

지원회화를 필요한 정보 한 가지를 찾는 사전처럼 사용하면 안 된다.

잘못된 방식:
- 존댓말 문제가 생김 → 존댓말만 찾음
- 명사가 궁금함 → 그 명사만 찾음
- 호칭이 궁금함 → 호칭만 찾음

올바른 방식:

> **대응하는 정발판 지원회화를 통째로 읽고, 두 인물이 서로에게 사용하는 한국어 화법 전체를 통합적으로 파악한 뒤 DLC 번역에 반영한다.**

정발 지원회화는 단순 참고문헌이 아니라
**“이 두 인물이 한국어판에서 서로 대화할 때 사용하는 언어 모델”**이다.

반드시 함께 파악할 것:

1. 상호 존비어
   - A → B 존댓말/반말
   - B → A 존댓말/반말
   - 감정이 격해져도 유지되는지
   - 짧은 응답만 반말로 섞이는지

2. 상호 호칭
   - 아빠 / 아버지 / 아버님 / 엄마 / 어머니
   - 이름 직접 호명
   - `너` 또는 이름 생략
   - 상황별 호칭 변화

3. 문장 어미
   - `~요`, `~죠`, `~네요`, `~습니다`
   - `~구나`, `~거라`, `~해`, `~한다`
   - 해당 관계에서 반복되는 특징적 어미

4. 명사와 공식 용어
   - 물건, 기술, 직업, 종족, 음식, 장소
   - 캐릭터가 실제 정발판에서 특정 사물을 뭐라고 부르는지

5. 일반 어휘 선택
   - 모두 / 다들
   - 기쁘다 / 즐겁다
   - 돕다 / 힘이 되다
   - 말하다 / 얘기하다
   - 같은 뜻이어도 해당 캐릭터가 실제로 선호하는 표현

6. 말버릇과 감탄사
   - 당황, 놀람, 웃음, 머뭇거림
   - 말더듬기
   - 특유의 추임새

7. 대화 리듬
   - 짧고 건조한가
   - 장황한가
   - 능청스러운가
   - 어린가
   - 문어적인가

8. 감정 표현 방식
   - 애정을 직접 표현하는가
   - 돌려 말하는가
   - 화낼 때 말투가 어떻게 변하는가
   - 쑥스러울 때 문장이 어떻게 무너지는가

9. 관계 한정 말투
   - 평소 타인에게 쓰는 말투와 가족에게 쓰는 말투가 다른가
   - 부모·자식, 부부, 형제 관계에서만 나타나는 특징이 있는가

10. 본편 콜백
    - DLC에서 본편의 사건, 농담, 고백, 조언, 기술명, 노래 가사 등을 재언급하면 새로 번역하지 않고 정발판 표현을 우선 재사용한다.

### 작업 순서

> **정발 지원회화 전체 독해 → 관계별 한국어 화법 세팅 → DLC 일본어 원문 해석 → 번역**

다음 방식은 금지:

> DLC 번역 → 문제 생길 때마다 정발판에서 필요한 것만 검색

# 1. 일본어 DLC 원문과 정발 지원회화의 역할

## 일본어 DLC 원문
다음을 결정한다.
- 장면에서 실제로 무슨 말을 하는지
- 의미
- 감정
- 농담 구조
- 화행 기능
- 의도적인 말투 붕괴

## 한국 정발판 지원회화
다음을 결정한다.
- 이 캐릭터가 한국어로 어떻게 말하는지
- 상대와 어떤 존비어를 쓰는지
- 어떤 호칭을 쓰는지
- 어떤 어휘와 명사를 쓰는지
- 감탄사와 말버릇
- 공식 용어

핵심:
> **일본어가 내용, 정발판이 한국어 캐릭터성의 기준이다.**

---

# 2. 효율화 관련 실패와 교훈

과거 문제:
- 일부 부모회화만 확인하고 나머지에 패턴을 일반화
- “평소 존댓말 캐릭터”라는 이유로 부모→자식 존댓말을 유지
- 필요한 항목만 검색하고 지원회화 전체를 읽지 않음

결과:
- 칸나 부모회화 존댓말 오류
- 이미 끝난 범위를 다시 전수 검수
- 조사 제어코드 재작업
- 전체 부모 존댓말 표를 뒤늦게 작성

교훈:

> **몇 분 아끼려는 생략이 수십 배의 재작업을 만든다.**

앞으로 효율화는:
- 참조 파일을 빨리 찾기
- 검사를 자동화하기
- 미리 표를 만들기

에만 사용한다.

**참조 파일 자체를 읽는 과정을 생략하는 방향의 효율화는 금지.**

---

# 3. 모두 ↔ 다들

피드백 사례:
- `모두들 조심해!` → `다들 조심해!`는 적절했음.
- 그러나 그 피드백을 일반화해서
  `모두한테 짐이 되고 싶지 않아.` → `다들한테 짐이 되고 싶지 않아.`
  로 바꾼 것은 부적절했음.

교훈:
- `みんな = 다들` 같은 고정 치환 규칙 금지.
- 문맥, 화자의 태도, 문장의 진지함을 보고 판단.

예:
- 직접적 구호/호소: `다들 조심해!`
- 진지하고 포괄적인 진술: `모두에게 짐이 되고 싶지 않아.`

단, 이것도 고정 규칙이 아니다.
**앞으로 모두 ↔ 다들은 번역 감각과 문맥으로 판단한다.**

# 4. 사용자 지정 표기

## 운동명
- `팔굽혀펴기` ❌
- `팔 굽혀 펴기` ✅

## 미타마의 표현
- `하이쿠` ❌
- `시` ✅
- 필요하면 `시구`, `시적인 표현`

일본 문화 형식명을 과도하게 노출하기보다 정발판 한국어 감각을 따른다.

# 5. 조사 제어코드

정발판 분석:

- `$KrP1|` = `(은)는`
- `$KrP2|` = `(을)를`
- `$KrP3|` = `(이)가`
- `$KrP4|` = `(과)와`
- `$KrP5|` = `(으)`
- `$KrP6|` = `(이)`

가변 이름 `$Nu` 뒤:
- `$Nu가` ❌ → `$Nu$KrP3|`
- `$Nu를` ❌ → `$Nu$KrP2|`
- `$Nu는` ❌ → `$Nu$KrP1|`
- `$Nu와` ❌ → `$Nu$KrP4|`
- `$Nu로` → `$Nu$KrP5|로`
- `$Nu랑` → `$Nu$KrP6|랑`
- `$Nu야` → `$Nu$KrP6|야`
- `$Nu라고` → `$Nu$KrP6|라고`
- `$Nu라는` → `$Nu$KrP6|라는`

주의:
- `$Nu님이`
- `$Nu씨에게`
- `$Nu 오라버니는`

처럼 변수 뒤에 고정 호칭이 붙었다면 조사는 그 호칭을 기준으로 하므로 `$KrP`를 기계적으로 넣지 않는다.

교훈:
> 새 규칙을 사용자에게 전달받았으면 “알겠다”로 끝내지 말고 **그 즉시 최종 QA 항목에 편입한다.**

---

# 6. 부모·자식 존비어

가장 큰 실패:
- 부모 지원회화를 통합적으로 읽지 않고
- 평소 캐릭터 말투나 일부 사례를 기준으로 부모·자식 말투를 추정함.

교훈:
> **일본어 원문의 존댓말보다 정발판 같은 관계의 한국어 현지화가 우선한다.**

또한:
> **고정 부모의 경향을 가변 부모 관계에 일반화하지 않는다.**

별도 참조:
`파엠_if_2세대_고정부모_존댓말_전체표.md`

이 표는 빠른 색인일 뿐,
실제 번역 때는 대응 `*_親子.txt`를 다시 읽는다.

# 7. 존댓말은 단순 O/X가 아니다

예: 셀키
- 기본적으로 아빠에게 `~요`
- 그러나 짧은 응답에서 `응!`, `아니야` 같은 반말형이 섞임

따라서:
- 존댓말 캐릭터니까 모든 문장에 `요` 삽입 ❌
- `응`이 한 번 나왔으니 반말 관계로 판정 ❌

**문장 단위 + 대화 흐름으로 판단한다.**

---

# 8. 호칭도 별도로 확인한다

부모 호칭은 캐릭터성의 일부다.

예:
- 시로 → 료마: `아버지`
- 키라기 → 타쿠미: `아버지`
- 아스기 → 사이조: `아빠`
- 미타마 → 아자마: `아버님`
- 카도리 → 츠바키: `아빠`
- 라자트 → 하야토: `아빠`

존댓말만 맞아도 호칭이 틀리면 정발 캐릭터성이 무너진다.

---

# 9. 말더듬기

과거 오류:
말더듬기를 “완성된 첫 음절 반복”으로 오판.

잘못:
- `카, 칸나` → `칸, 칸나`
- `괘, 괜찮아` → `괜, 괜찮아`

올바른 예:
- `カ、カンナ` → `카, 칸나`
- 정말 → `저, 정말`
- 얼마 → `어, 얼마`
- 갑자기 → `가, 갑자기`
- 말 안 → `마, 말 안`
- 엄마 → `어, 엄마`
- 물론 → `무, 물론`
- 괜찮아 → `괘, 괜찮아`
- 별로 → `벼, 별로`
- 혹시 → `호, 혹시`
- 일단 → `이, 일단`

말더듬기는 철자 반복이 아니라
**실제 발화가 중간에서 끊기는 느낌**이다.

# 10. 일본어 감탄사 음차 금지

금지:
- はわわ → 하와와
- あわわ → 아와와
- ひゃあ → 햐아
- うわわわ → 우와와와

정발판 같은 캐릭터 표현과 한국어 감정 기능을 우선한다.

예:
- 펠리시아 `はわわ` → `으아아`, `흐아아`
- `あわわ` → `어어어…`, `으아아…`, `아, 아니…!`
- `ひゃあっ` → `꺅!` / `으악!`
- `わわっ` → `앗!`, `어엇!`
- `あたたた` → `아야야야!`

# 11. 대시

# 12. 전각 공백

일반 한국어 문장에서는 U+3000 금지.

예외:
`「첫째 줄
　둘째 줄」`
처럼 열린 인용문의 다음 표시 행 들여쓰기라는 명확한 서식 기능이 있을 때.

즉:
- 전각 공백 무조건 제거 ❌
- 일본어 원문에 있으니 무조건 유지 ❌

기능을 보고 판단.

# 13. 한국어 형태론

과거 오류:
- `조미료를 뒤집어쓰는다고!?` ❌
- `조미료를 뒤집어쓴다고!?` ✅

검사:
- `-ㄴ다고 / -는다고`
- `-냐고`
- 과거형
- 시제
- 받침 결합
- 조사
- 높임법

사용자가 특정 어절을 지적하면 해석론보다 먼저 형태소/활용 오류를 확인한다.

# 14. 정발판 자체 표기 존중

정발판 스타일이 명확하면 일반 맞춤법 취향으로 고치지 않는다.

예:
- `$Nu님`
- `료마님`
- `카밀라님`
- `제이콥씨`
- `하야토씨`

반면 실제 정발에:
- `$Nu 오라버니`

처럼 띄어쓰기가 있다면 그대로 유지.

즉 특정 사례를 또 무리하게 일반화하지 않는다.

# 15. 확인된 공식 용어

- `コウガ公国` → `코가 공국`
- `絡繰` → `꼭두각시`
- `漬物` → `야채 절임`
- `アウェイキング・ヴァンダー` → `어웨이킹 밴더`
- `ノスフェラトゥ` → `노스페라투`

시구레 노래:
- `ユラリ、ユルレリ…` → `하늘거리는 물거품…`
- `うたかた…おもい…めぐるはかり` → `정처없는 마음의 저울…`
- `つたう、みなすじ…そのてが…ひらく…あすは…`
  → `이어지는 물줄기… / 그 손이 개척하는 미래…`

공식 용어는 개인적 자연스러움을 이유로 새로 번역하지 않는다.

# 16. 사용자 직접 교정에서 얻은 번역 감각

## 어미는 태도를 담는다
`그렇게 당황하다니, 귀여운 아이.`
→ `그렇게 당황하다니, 귀여운 아이네.`

교훈:
종결 어미가 화자의 태도와 온도를 결정한다.

## 접속어의 구어성
`하지만 그 쑥스러워하는 얼굴도 귀엽구나.`
→ `근데 그 쑥스러워하는 얼굴도 귀엽구나.`

교훈:
일본어 접속사를 문어적으로 직대응하지 않는다.

## 조건의 강도
`혹시 모기가 날아오면`
→ `만약 모기가 날아오면`

교훈:
`혹시/만약`의 조건성 차이를 본다.

## 제안과 명령
`무슨 일 있으면 엄마한테 말해 봐?`
→ `무슨 일 있으면 엄마한테 말해 볼래?`

교훈:
문장의 화행 기능을 본다.

## 감정적 강조
`싸울 수가 없어!`
→ `싸울 수가 없다구!`

교훈:
정보보다 감정이 중요한 대사는 한국어 구어적 강조를 살린다.

## 인용문 말투
`활은 맞히는 게 아니라, 저절로 맞는 거야.`
→ `활은 맞히는 게 아니라, 저절로 맞는 것.`

교훈:
격언/인용문의 문체는 평상 대사와 다를 수 있다.

## 출처 표현
`아버지한테 배운 거예요?`
→ `아버지한테서 들은 말인가요?`

교훈:
원문의 의미 관계를 정확히 잡는다.

## 의성어
`활로 쾅~ 하고요!`
→ `활로 슉~ 하죠!`

교훈:
일본어 음가가 아니라 실제 행동 이미지에 맞는 한국어 의성어를 쓴다.

## 양태
`사용인보다 군인이 천 배는 낫다`
→ `사용인보다 군인이 천 배는 낫겠다`

교훈:
사실 판단 / 추정 / 의향을 구분한다.

## 담화 관계

# 24. 플레이어 말투 분기와 정발판의 누락 ― 매우 중요

## 배경
일본판에는 플레이어 캐릭터의 말투에 따라 여러 분기가 존재한다.

예:
- 남성 주인공: `PCM1`, `PCM2`, `PCM3` 등
- 여성 주인공: `PCF1`, `PCF2`, `PCF3` 등

그러나 영문판은 영어의 언어적 특성상 일본어처럼 말투·종결어미 차이를 크게 나눌 필요가 없어서
**일본판의 여러 화법 분기를 삭제하고 대표 분기만 남겼다.**

남은 대표 분기:
- `PCM1` = 반말 남성
- `PCF2` = 반말 여성

한국 정발판도 이 축약된 분기 구조를 따르므로,
정발 K에 `PCF1`, `PCF3`, `PCM2`, `PCM3` 등의 대응 지원회화가 없을 수 있다.

## 가장 중요한 결론

> **정발 K에 대응 분기가 없다는 사실을 “그 말투를 정발판이 반말로 현지화했다”는 증거로 해석하면 안 된다.**

즉:
- 일본 DLC `PCF1`이 존댓말/격식 분기라면 그 화법 차이를 살려야 한다.
- 일본 DLC `PCF3`이 또 다른 개성적 말투라면 그 차이도 살려야 한다.
- 정발 K의 `PCF2`를 근거로 PCF1/3을 전부 반말로 평탄화하면 안 된다.
- 남성 쪽도 마찬가지로 정발 K `PCM1`만 보고 일본판 `PCM2/3`의 말투 차이를 지우면 안 된다.

## 정발 K 대표 분기의 올바른 사용법

정발 K `PCM1` / `PCF2`는 다음을 참고하는 데 매우 유용하다.
- 캐릭터가 플레이어를 부르는 호칭
- 공식 명사·고유명사
- 본편 사건의 번역
- 캐릭터 고유 어휘
- 상대 캐릭터의 한국어 화법
- 본편 콜백 문구
- 조사 제어코드 및 정발 문장 스타일

하지만 **플레이어 자신의 말투/존비어 분기**는
정발 대표 분기로 덮어쓰지 않고 **일본판 해당 분기 원문을 기준으로 보존**한다.

## 실전 판정 순서

플레이어 말투 분기가 포함된 DLC라면:

1. 일본판 해당 `PCM#/PCF#` 원문에서 플레이어의 화법을 먼저 파악한다.
2. 그 분기가 정발 K에 실제로 존재하는지 확인한다.
3. 존재하면 정발 K를 직접 대조한다.
4. 존재하지 않는다면:
   - 정발 대표 분기(`PCM1`/`PCF2`)는 어휘·호칭·세계관 표현 참고용으로 사용
   - **플레이어의 화법 자체는 일본판 분기 차이를 살려 한국어로 재현**
5. 다른 등장인물의 말투는 그 인물의 정발 지원회화를 기준으로 맞춘다.

## 실패 사례

칸나(남) DLC의 `PCF1`을 검수하면서
정발 K `カンナ男_プレイヤー女_親子.txt`의 `PCF2` 반말을 과도하게 적용해
일본판 `PCF1`의 `です/ます` 계열 차이를 없애려 했던 것은 잘못이다.

이 경우 정발 K에는 애초에 PCF1 분기가 없는 것이므로,
PCF2는 **PCF1의 존비어를 판정하는 근거가 될 수 없다.**

교훈:
> **“정발판에 없는 것”과 “정발판이 다르게 번역한 것”을 절대로 혼동하지 않는다.**

# 25. 2026-08-21 칸나(남) 통합 재검수에서 추가로 얻은 교훈

## 번역의 실제 단위는 “한 문장”이 아니다

이번 재검수에서 가장 크게 확인된 점:

> **번역의 단위는 `인물 + 상대와의 관계 + 두 사람이 공유한 과거 + 현재 장면`이다.**

한 줄의 일본어만 보면 무난해 보여도,
본편에서 두 사람이 이미 겪은 사건을 알고 나면 번역해야 할 명사·동사·말끝이 달라진다.

예:
- 제이콥: 홍차 콜백 → 정발의 `따뜻한 물과 설탕을 넣고…` 계승
- 사이조: 기록 명칭 → `관찰 기록`이 아니라 정발의 `감시 기록`
- 료마: 과거/미래/추억 콜백 → 본편 정발 문장을 최대한 계승
- 하야토: `$Nuと手紙か…` → 단순 `$Nu와 편지라…`가 아니라, 둘이 편지를 계기로 쌓은 과거가 떠오르는 장면으로 해석
- 아서: `방재 훈련`, 머리부터 물을 뒤집어쓰는 본편 사건을 공식 표현 기준으로 대조
- 키튼: `ガルー`는 정발 GameData의 `늑대 인간`을 사용

## 지원회화는 원문보다 위에 있는 절대 규칙이 아니다

지원회화를 통합적으로 보는 것과
일본어 DLC 원문의 의도적 차이를 지우는 것은 전혀 다르다.

특히 플레이어 말투 분기처럼
정발판에 해당 분기가 삭제되어 없는 경우,
대표 정발 분기의 말투를 억지로 덮어쓰면 안 된다.

반대로 카제·포레스트처럼
일본어 원문은 자식에게 `です/ます`를 쓰더라도
**같은 부모회화가 정발 K에 실제로 존재하고, 거기서 부모→칸나를 반말로 현지화한 것이 확인된다면**
그 관계의 한국어판 말투는 정발 K를 따른다.

즉 판정 기준:

1. 같은 분기의 정발 K가 실제 존재하는가?
2. 존재한다면 일본판과 한국판을 직접 짝으로 비교한다.
3. 존재하지 않는다면 정발 대표 분기로 원문 분기 차이를 지우지 않는다.

따라서 참조 범위는:
1. `シグレ_<부모>_親子.txt`
2. 장면에서 아주라와의 과거를 언급하면 `<아버지>_アクア.txt` 또는 `アクア_<아버지>.txt`
3. 필요하면 메인 시나리오/외전의 실제 사건
까지 확장한다.

핵심:
> **현재 화자 둘만 보고 번역하지 말고, 대사가 호출하는 모든 관계와 공유된 과거를 따라가서 공식 번역을 확인한다.**

## 26-2. 시구레의 부모 대상 화법

정발 K 부모 지원회화에서 시구레는 부모에게 매우 안정적으로:
- 아버지 → `아버지`
- 아주라 → `어머니`
- 기본 존댓말
을 사용한다.

감정이 올라가거나 놀리거나 민망해하는 장면에서도
기본 존댓말 체계가 쉽게 무너지지 않는다.

따라서 시구레의 가족 대화는
`존댓말 여부`뿐 아니라 **차분하고 예의 바른 청년의 리듬**을 유지하는 것이 중요하다.

## 26-3. 부모→시구레는 모두 반말이라도 캐릭터별 리듬이 전혀 다르다

단순히 `부모→자식 = 반말`만 기록해서는 부족하다.

예:
- 제이콥: 건조하고 엄격하며 명령형이 강함
- 카제: 부드럽고 차분한 아버지 말투
- 료마: 무게감 있고 `~마`, `~거라` 계열이 자연스러움
- 타쿠미: 다소 퉁명스럽고 쉽게 쑥스러워함
- 사이조: 짧고 딱딱함
- 카덴: 밝고 다정함
- 히나타: 호쾌하고 직선적
- 아자마: 비꼬는 표현과 독설이 섞임
- 츠바키: 말끝을 `―`로 늘이는 정발 특성이 강함
- 하야토: 고풍스럽고 명령조가 섞임
- 젠더: 위엄 있고 단정함
- 리오: 이성적이고 절제됨
- 베니: 말수가 적고 말줄임이 많음
- 키튼: 직선적이고 활기참
- 아서: 정의·열혈·과장된 영웅 어조
- 오딘: 중2병식 과장어와 명명법
- 라슬로: 부드럽고 능청스러우며 춤/연애 관련 어휘가 많음
- 닐스: 중의적·도발적 표현

## 26-4. 카제 사례 ― 동일 관계의 실제 정발 현지화가 일본어 표면 존댓말보다 우선

일본판 `シグレ_スズカゼ_親子`에서 카제는 시구레에게 `です/ます`를 사용한다.
하지만 같은 관계의 정발 K 파일에서는 카제→시구레가 명확한 반말로 현지화되어 있다.

따라서 DLC에서도:
- 일본어 표면의 `です/ます`를 기계적으로 한국어 존댓말로 옮기지 않는다.
- **같은 관계의 정발 K가 실제 존재하면 그 현지화 선택을 우선한다.**

이 사례는 플레이어의 삭제된 말투 분기와 다르다.

- 삭제된 `PCM2/PCM3/PCF1/PCF3` → 정발판에 동일 분기가 없으므로 일본판 화법 차이를 보존
- 카제→시구레 → 동일 관계의 정발판이 실제 존재하므로 정발 K 현지화를 따라감

## 26-5. 본편 콜백은 공식 문구를 적극 재사용

시구레 DLC에서 확인한 대표 사례:

### 베니 × 아주라
- `縁の歌` → **`인연의 노래`**
- `연결의 노래`처럼 새로 만들지 않는다.

### 아서 × 아주라
청혼 노래의 공식 정발 가사:
- `소년이 사랑에 빠진 것은…`
- `소녀의 슬프고 허무한 눈동자가`
- `너무나도 아름다웠기에…`

DLC에서 같은 가사를 부르면 공식 번역을 재사용한다.
정발 용어는 `프로포즈`.

### 오딘 × 아주라
공식 명명:
- `무자비한 위닝 메모리`
- `기쁨의 트롤링`

오딘의 새 조어도 기존 정발 명명 감각에 맞춘다.

### 라슬로 × 아주라
본편의 춤 관련 핵심 문구:
- `「나를 봐 줘」`
- `「이 춤을 봐 줘」`

DLC에서 같은 기억을 말하면 그대로 재사용한다.

## 26-6. 닐스의 말투는 “야한 표현을 많이 쓰는 캐릭터”로만 보면 부족하다

아주라와의 본편 지원회화에서 닐스는
아주라 앞에서는 일부러 평소의 이상한/음담패설성 말투를 자제한다고 설명한다.

따라서 DLC의:
`俺の言葉遣いの意味はアクアには伝えてある`
같은 문장은 추상적으로 `내 말투의 의미`라고 옮기기보다,

> `내가 왜 그런 말투를 쓰는지는 아주라한테 설명해 뒀지만…`

처럼 **본편에서 실제로 설명한 사정**을 복원하는 편이 자연스럽다.

## 26-7. 시구레의 노래 관련 어휘는 공식 번역을 먼저 확인

시구레와 아주라는 노래가 캐릭터 정체성의 핵심이라
가사·주선율/부선율·노래 제목·과거 노래 사건을 새로 번역하기 전에
반드시 본편 정발 대사를 먼저 검색한다.

특히 기존 정발 가사가 있으면
새로운 문학적 번역보다 공식 가사 재사용이 우선이다.

## 26-8. 일본어 의성적 음치 표현도 한국어 기능으로 옮긴다

히나타의 심한 음치 표현 `ぼえぇぇ…` 같은 것은
일본어 음가를 그대로 옮기는 것이 목적이 아니다.

한국어 장면에서:
- 알아듣기 힘든 괴상한 노랫소리
- 시구레가 “그런 가사는 없다”고 정정하는 개그
가 자연스럽게 성립하도록
`으어어어…`류처럼 기능적으로 현지화한다.

## 26-9. 이번 작업의 추가 자기 점검 질문

> **“현재 두 사람이 말하고 있지만, 이 대사가 제3자와의 본편 관계나 사건을 호출하고 있지는 않은가?”**

그렇다면 현재 두 사람의 지원회화만 보고 끝내지 않는다.

> **“일본어의 존댓말을 옮긴 것인가, 아니면 같은 관계의 정발 K가 실제로 어떤 화법을 선택했는지 확인한 것인가?”**

동일 관계의 공식 K가 존재하면 실제 현지화 선택을 확인한다.

# 27. 콜백 원출처 회화까지 통합적으로 읽기 ― 필수

## 새로 확인된 맹점

예를 들어 `칸나(남)_젠더` DLC를 번역한다고 해서
기본적으로 `カンナ男_マークス_親子.txt`만 읽고 끝내면 부족하다.

DLC 안에서 젠더가 카무이(여)와 있었던 본편 일을 회상한다면,
그 순간 **카무이(여)↔젠더의 실제 본편 지원회화까지 추가로 읽어야 한다.**

### 실제 발생한 오류

본편 정발 지원회화에서 카무이(여)는 젠더에게
`검이 거칠다`는 취지로 지적했다.

그런데 DLC에서 젠더가 그 말을 칸나에게 전하는 장면을 새로 번역하면서
`검이 흐트러졌다`처럼 다른 표현으로 바꾸면,
**같은 과거 사건을 회상하는데 정발판 내부에서 표현이 달라지는 불일치**가 생긴다.

이런 오류는 `칸나↔젠더` 부모회화만 읽어서는 잡기 어렵고,
콜백이 가리키는 `카무이(여)↔젠더` 원출처 지원회화까지 읽어야 잡힌다.

## 최종 작업 원칙

### 1. 작업 시작 전 ― 기본 참조 회화
번역 대상 두 인물의 관계를 보여 주는 정발판 본편 회화를 먼저 통째로 읽는다.

예:
`칸나(남)_젠더` DLC라면:
- `カンナ男_マークス_親子.txt`

여기서 파악:
- 상호 존비어
- 호칭
- 어미
- 일반 어휘
- 명사
- 말버릇
- 감정 표현
- 대화 리듬
- 관계 특유의 캐릭터성

### 2. 번역 중 ― 콜백 감지
일본어 DLC를 읽다가 다음이 나오면 즉시 콜백으로 취급한다.

- “예전에 네 엄마가…”
- “그때 네가 이렇게 말했지”
- 과거의 특정 선물/사건
- 본편에서 했던 훈련
- 연애/청혼 장면
- 노래/춤/편지/반지
- 본편의 특정 농담
- 과거에 사용한 고유 표현
- 특정 행동이나 평가를 다시 언급함

### 3. 콜백 발견 시 ― 원출처 회화 추가 독해
콜백과 직접 연결된 본편 지원회화를 **해당 문장만 검색하지 말고 전체를 읽는다.**

예:
`칸나(남)_젠더`에서 젠더가 카무이(여)의 검술 지적을 회상
→ `카무이(여)↔젠더` 본편 지원회화 전체 독해

여기서 확인:
- 당시 정확한 정발 표현
- 전후 맥락
- 두 인물의 말투
- 같은 단어가 어떤 의미로 쓰였는지
- 그 사건을 두 사람이 어떤 감정으로 받아들였는지

### 4. DLC에서는 공식 콜백 표현을 우선 재사용
같은 사건, 같은 지적, 같은 농담, 같은 명사라면
가능한 한 **본편 정발 표현을 그대로 계승**한다.

> **콜백은 새로 번역하는 문장이 아니라, 기존 정발판 대사를 다시 기억해서 말하는 문장으로 본다.**

단, 시점이나 화자가 바뀌어 그대로 복사하기 어렵다면
핵심 어휘와 의미 관계를 유지한 채 자연스럽게 변형한다.

## 매우 중요한 구별

- 기본 관계 회화 = 항상 작업 시작 전에 읽음
- 콜백 원출처 회화 = 번역 도중 콜백을 발견하는 즉시 추가로 읽음

즉:

> **기본 참조는 선행 독해 + 콜백 참조는 동적 확장**

이 방식이 최종 프로세스다.

## 콜백 검수 질문

각 MID를 확정하기 전에:

> “이 대사에서 과거의 특정 사건이나 말을 회상하고 있는가?”

YES라면:

> “그 사건의 정발 원출처 회화를 실제로 전체 독해했는가?”

YES가 아니라면 번역을 확정하지 않는다.

그리고:

> “원출처 정발판에서 쓰던 핵심 표현을 DLC에서 불필요하게 다른 말로 바꾸지는 않았는가?”

를 마지막에 다시 확인한다.

# 28. 부모/배우자 정체를 모른다는 이유로 참조를 생략하지 않는다 ― 절대 규칙

가변 부모·배우자 구조가 있는 회화에서
콜백의 대상이 누구인지 즉시 알 수 없더라도
**그 사실은 참조를 생략할 이유가 되지 않는다.**

예:
- `칸나의 엄마가 누군지 모르겠다`
- `시구레의 아버지가 누구인지 이 MID만 보고 확신이 안 든다`
- `이 회상에서 말하는 배우자가 어느 지원회화 조합인지 바로 모르겠다`

이 경우 절대:
> “누군지 모르겠으니 일반적인 말투로 번역”
> “정확한 원출처를 못 찾았으니 넘어감”

하지 않는다.

## 반드시 할 일

1. MID 이름과 내부 캐릭터 ID 확인
2. 일본판 DLC 분기 구조 확인
3. 해당 자식의 고정 부모 / 가변 부모 구조 확인
4. 현재 MID의 상대 캐릭터가 누구인지 확정
5. 그 상대와 자식의 다른 부모(배우자)가 누구인지 관계 구조로 역산
6. 정발 K/J 지원회화 파일 목록에서 정확한 원출처 조합을 찾음
7. 필요하면 같은 사건을 가리키는 부부/부모 지원회화를 추가 검색
8. **정체가 확정된 뒤에야 번역을 확정**

## 핵심 원칙

> **“누군지 모르겠다”는 참조 종료 조건이 아니라, 추가 조사 시작 신호다.**

부모/배우자 정체를 확정하지 못한 상태라면
해당 콜백이 포함된 MID는 **미확정 상태**로 간주한다.

## 체크 질문

콜백이 가족 관계를 포함한다면 반드시 묻는다.

> “여기서 말하는 엄마/아빠/배우자는 정확히 누구인가?”

답을 못 하면:

> “그 관계를 확인하기 위해 어떤 파일/분기/지원회화를 더 봐야 하는가?”

를 먼저 해결한다.

그리고 최종적으로:

> “정체를 모르겠다는 이유로 확인 가능한 공식 회화를 건너뛴 것은 없는가?”

를 QA 항목으로 확인한다.

# 29. 2세대 고정 부모 관계 마스터표 상시 참조

별도 파일:
`파엠_if_2세대_고정부모_관계_마스터표.md`

이 표는 존댓말 표가 아니라 **관계 확인용 1차 인덱스**다.

작업 전 반드시:
1. 자식의 내부 ID 확인
2. 고정 부모 확인
3. 반대쪽 부모가 가변인지 확인
4. 현재 MID가 어느 부모 조합인지 확정
5. 콜백이 나오면 해당 부모/배우자 지원회화로 즉시 확장

특히:
- 칸나(여) → 고정 아버지: 남성 주인공
- 칸나(남) → 고정 어머니: 여성 주인공
- 시구레 → 고정 어머니: 아주라
- 그 외 19명 → 고정 아버지 + 가변 어머니

이 관계를 기억에 의존해 추정하지 않는다.

# 30. 콜백 원출처는 지원회화에 한정되지 않는다 ― 이벤트/외전/본편 스크립트까지 추적

## 시구레 재검수에서 확인된 추가 맹점

콜백이 과거의 특정 사건을 가리킨다고 해서
원출처가 반드시 `*_親子.txt`나 부부 지원회화인 것은 아니다.

시구레 DLC 첫 회화는
아주라가 과거 비경 습격 당시 시구레를 지키며 했던 말을 직접 회상한다.

그 원출처는 지원회화가 아니라
**시구레 외전 `X003 「가희와 함께」` 본편 이벤트 스크립트**다.

정발 K 원출처:
- `자, 난 여기 있어.`
- `이 아이에게는 손대지 마…`
- `노릴 거면 나를 노려!`

따라서 DLC에서 같은 말을 시구레가 인용할 때는
새로 번역하지 않고 이 정발 문구를 우선 재사용한다.

번역 중 특정 과거 사건/대사/행동이 나오면 다음 순서로 원출처를 찾는다.

3. 형제·친구 등 관련 지원회화

## 소피(ゾフィー) E033 배치에서 추가 확인한 규칙

### 1. 소피의 부모 대상 화법: `아빠/엄마 + 존댓말`
소피의 정발 한국어 부모 지원회화를 고정 아버지 사일러스 및 가변 어머니 전원 기준으로 다시 읽어 확인했다.

- 소피 → 사일러스: `아빠`라고 부르지만 문장은 존댓말.
- 소피 → 가변 어머니: `엄마`라고 부르지만 문장은 존댓말.
- 부모 → 소피: 각 캐릭터 고유의 반말/어조를 유지.

따라서 일본어 DLC에서 소피가 부모에게 반말을 사용하더라도, 한국어 현지화에서는 동일 관계의 정발판 화법을 우선하여 `엄마/아빠 + ~요/~세요`로 옮긴다.

핵심 교훈:
> 친근한 부모 호칭과 존댓말은 모순이 아니다. 한국 정발판이 만든 관계별 언어 습관을 한 덩어리로 따라야 한다.

### 2. `アヴェル`의 정발 표기는 `에이블`
소피의 애마 `アヴェル`은 정발 한국어 지원회화에서 **에이블**로 표기된다.

- `아벨` 등 임의 음역 금지.
- 에이블과 관련한 소피의 덜렁대는 일화, 말에게 휘둘리는 묘사도 정발 지원회화의 어휘 감각을 우선한다.

### 3. DLC의 부부/과거사 콜백은 원 지원회화까지 동적 확장
이번 소피 배치에서 실제로 다음 콜백을 원 지원회화까지 추적했다.

- 여성 카무이 ↔ 사일러스:
  - 어릴 적 친구였으나 카무이가 사일러스를 잊고 있었음.
  - 재회한 뒤 서로 `첫눈에 반했다`는 사실이 S지원에서 명시됨.
  - DLC의 소피가 이를 놀리는 장면은 이 정발 표현을 기준으로 번역.
- 사쿠라 ↔ 사일러스:
  - 사쿠라가 사일러스에게 저주가 걸렸다고 착각.
  - 저주에 잘 듣는 약을 구하려고 산에까지 감.
  - DLC의 `저주받은 아빠를 위해 산속에 갔다`는 회상은 이 사건의 콜백.
- 셀레나 ↔ 사일러스:
  - 노력 대결에서 검 휘두르기를 시작해 결국 아침까지 계속함.
  - DLC에서 소피가 셀레나의 승부욕을 지적하며 이 일을 폭로하므로 정발의 `아침까지 검을 휘두르다` 표현과 사건 구조를 기준으로 번역.

즉:
> 부모회화 안에 배우자/과거 사건을 가리키는 문장이 나오면, 그 사실만 대충 기억해 번역하지 말고 해당 지원회화 전체를 찾아 한국 정발의 실제 표현까지 확인한다.

- 카밀라: 다정하고 포용적이지만 훈육할 때는 단호함.
- 엘피: 느리고 담백하며 먹는 것에 대한 진지함이 자연스럽게 섞임.
- 샤를로트: 직설적이고 현실적이며 연애/인기 문제를 거리낌 없이 말함.
- 페리: 자기 이름을 1인칭으로 쓰며 어린아이 같은 논리와 감정 표현.
- 베르카: 짧고 조용하며 감정 표현이 절제됨.
- 셀레나: 경쟁심과 츤데레식 부정/발끈이 핵심.
- 닉스: 성숙하고 차분하며 자신의 저주를 담담히 설명함.

공통 관계 규칙은 `소피→부모 존댓말`이고,
부모의 캐릭터성은 각 부모 지원회화 전체에서 별도로 배운다.

### 6. 유효한 U+3000 사용 사례 재확인
카밀라 회화의 직접인용:

`「아아… 내 귀여운 에이블…\n　사랑해…」`

처럼 여는 따옴표 `「` 안의 발화가 literal `\n` 뒤에도 계속될 때만 두 번째 줄 첫머리에 U+3000 `　`을 둔다.

이번 배치 QA에서 U+3000은 이 한 곳만 의도적으로 남겼다.

### 7. 소피 배치 기술 QA 기록

- source/output control sequence exact match
- `$k`: 643 / 643
- `$p`: 219 / 219

- `$Wm`: 46 / 46
- `$SvpVOICE_`: 420 / 420

- U+2014 `—`: 0

## 미도리 배치 추가 학습 (23 MID)

### 1. 표시명은 `미도리`
일본어 내부 ID는 `ミドリコ`지만 정발 한국어 표시명은 **미도리**다.

- 내부 MID/제어코드: `ミドリコ` 유지
- 가시 대사: `미도리`
- `미도리코`로 음역하지 않는다.

### 2. 미도리→부모 화법: 존댓말 중심 + 어린아이식 반말 반응 혼합
미도리는 소피처럼 부모에게 문장 전체를 안정적으로 존댓말만 쓰는 타입이 아니다.

정발 부모회화의 실제 패턴:
- 설명/부탁/걱정: `~요`, `~주세요`, `~했어요`
- 짧은 반응/감정 폭발: `응!`, `아빠!`, `엄마!`
- 감정이 강해지면 한 문장 안에서도 어린 반말이 자연스럽게 섞일 수 있음.
- 부모→미도리는 기본 반말.

따라서 일본어 원문이 어린 반말이라고 해서 전부 반말로 옮겨도 안 되고,
반대로 관계 규칙만 보고 모든 문장을 존댓말로 강제해도 안 된다.

### 3. 자기 이름을 1인칭으로 쓰는 것이 핵심 캐릭터성
미도리는 정발에서도 `나/저`보다 **`미도리`**를 1인칭처럼 자주 쓴다.

예:
- `미도리가 약을 만들어 왔어요!`
- `미도리는 엄마가 정말 좋아요!!`
- `미도리 약속할게요!!`

이를 일반적인 한국어 화자처럼 `나/저`로 평준화하면 캐릭터성이 크게 약해진다.

### 4. 조숙함과 유아성이 동시에 있어야 한다
미도리의 말투는 두 층이 공존한다.

조숙한 면:
- 약
- 약초
- 연구
- 제조법
- 치료/소독
- 다른 사람을 돌보는 태도

어린 면:
- 칭찬받으면 바로 들뜸
- 울음
- `응!`
- 부모에게 어리광
- 유치한 말장난/잘못 발음
- 자기 이름 1인칭

약 이야기만 보고 지나치게 성숙한 연구자 말투로 만들지 않는다.

### 5. 약 관련 정발 기준
이번 배치에서 정발 부모회화 및 배우자 지원을 통해 확인한 표현:
- `薬` → **약**
- `薬草` → **약초**
- `研究` → **연구**
- `製造法` → **제조법**
- `しびれ薬` → **마비약**
- `しびれ薬を混ぜた団子` → **마비약을 섞은 경단 / 마비약 경단**
- `調合` 문맥 → **약 조합 / 조합**

지나치게 현대 의학 전문용어로 바꾸지 않는다.

### 6. 직접 본편 콜백은 배우자 지원까지 확인
이번 DLC의 부모 대화에는 부모회화 밖의 배우자 지원 콜백이 다수 있다.

확인 사례:
- 여성 카무이 × 카제: 카제가 과거의 죄를 고백하고 카무이에게 용서받은 사건.
- 세츠나 × 카제: 카제가 `언제 위험에 처할지 모르는 당신을 제가 지키고 싶은 겁니다`라고 말한 관계.
- 오보로 × 카제: 쥐 퇴치에 **마비약을 섞은 경단**을 사용한 사건.
- 카밀라 × 카제: 카밀라가 연 **티타임**에서 카제가 많은 여성들에게 둘러싸인 사건.
- 하나 × 카제: 하나가 전투 중 쉽게 흥분해 무모하게 행동하는 것을 카제가 걱정하고 지키려 한 관계.

DLC가 이런 일을 자녀의 입으로 회상할 경우,
부모회화만으로 번역을 끝내지 말고 해당 배우자 지원도 확인한다.

### 7. `むちゃぶるい` 같은 어린 말실수는 기능을 살린다
원문이 일부러 틀린 단어를 말하고 부모가 교정하는 장면은
그냥 정확한 단어로 번역하면 장면 기능이 사라진다.

따라서:
- 아이가 잘못 말함
- 부모가 자연스럽게 바로잡음
- 아이가 `맞게 말했어!`라고 우김

이라는 3단 구조를 한국어에서도 유지한다.
직역 음역보다 **한국어에서 알아들을 수 있는 어린 말실수**가 우선이다.

### 8. 펠리시아의 일본식 비명은 표면 음가를 베끼지 않는다
`はぅぅ`, `はわわわわっ` 등은 정발 캐릭터성과 장면에 맞게
`으으`, `으아앗!?` 등 자연스러운 한국어 반응으로 처리한다.

`하와와` 금지 원칙을 다시 확인했다.

### 9. 부모별 어조는 별도 모델로 유지
미도리의 공통 화법과 별개로 부모의 대사는 각 정발 부모회화 전체에서 배운다.

예:
- 아주라: 차분하고 서정적
- 펠리시아: 허둥대고 부드러움
- 린카: 단단하고 훈련 중심
- 오로치: 고풍스럽고 장난기 있음
- 카게로: 짧고 무게감 있음
- 세츠나: 느슨하고 뜸을 들임
- 카밀라: 다정하고 관능적인 과장
- 엘리스: 밝고 아이 같은 활기
- 샤를로트: 직설적이고 현실적, 인기/연애 화제에 적극적
- 엘피: 느리고 담백함
- 페리: 어린 논리와 폭력적 어휘의 대비
- 베르카: 짧고 절제됨
- 셀레나: 발끈하면서도 정이 많음
- 닉스: 차분하고 성숙하며 저주 문제를 담담히 다룸

## 시그버트 배치 추가 학습 (15 MID)

### 1. 시그버트→부모 화법: 안정적인 존댓말
정발 부모 지원회화를 전체 대조한 결과, 시그버트는 고정부모 젠더뿐 아니라 가변 어머니들에게도 기본적으로 존댓말을 유지한다.

대표 패턴:
- `어머니. 여기 계셨군요.`
- `괜찮으세요?`
- `감사합니다, 어머니.`
- `~해 주시겠어요?`
- `~인 것 같습니다.`
- `~겠습니다.`

중요:
- 일본어 DLC의 시그버트 대사가 `~だよ`, `~かい`처럼 표면상 반말형이어도 한국 정발의 부모 관계 화법을 무시하고 반말로 옮기지 않는다.
- 시그버트의 존댓말은 지나치게 관료적이지 않다. `~입니다/~습니까`뿐 아니라 자연스러운 `~요`가 섞인다.
- 부모→시그버트는 기본 반말.

### 2. 시그버트의 핵심 캐릭터성: 왕자다운 격식 + 자기압박
시그버트는 단순히 예의 바른 왕자가 아니다.

정발 부모회화에서 반복되는 핵심:
- 아버지 젠더를 절대적인 기준처럼 여김.
- 자신을 아버지와 계속 비교함.
- 백성의 기대와 후계자의 책임에 압박을 느낌.
- 지나치게 깊이 생각하고 위축되는 경향.
- 그러면서도 백성과 동료를 생각하는 책임감이 강함.
- 부모에게 칭찬받으면 진지하게 기뻐하고 감사함.

따라서 DLC에서도:
- 너무 자신만만한 왕자 말투 ❌
- 지나치게 비굴한 말투 ❌
- 책임감 있고 진지하지만 은근히 자신을 낮춰 보는 말투 ✅

### 3. 젠더 호칭: `아버지`가 기본, `아버님`은 문맥적 격상
정발 `시그버트_젠더_부모` 지원에서 시그버트의 기본 직접 호칭은 **`아버지`**다.

다만:
- `아버님처럼 모두에게 도움이 되지는 못할 테니까요…`
처럼 문장 안에서 격식이 올라간 **`아버님`**도 실제로 존재한다.

따라서:
- `父上 = 아버지`를 기본값으로 삼되
- 무조건 전부 `아버지`/전부 `아버님`으로 기계 통일하지 않는다.

### 4. `パパ上` 개그는 이번 장면에서 `아빠님`
젠더가 “오늘만은 나를 `パパ`라고 불러 보는 건 어떠냐”고 제안하자,
시그버트는 자신의 평소 격식을 버리지 못하고 `パパ上`이라는 혼종 호칭을 만든다.

이번 DLC에서는:
- `パパ` → `아빠`
- `パパ上` → **`아빠님`**

으로 처리.

이유:
- `아빠`의 어린 친근함
- 시그버트가 버리지 못한 존대 감각
두 요소가 동시에 드러난다.

주의:
> `パパ上 = 아빠님`은 일반 대응표가 아니다. 이 정확한 말장난 장면의 기능을 살리기 위한 선택이다.

### 5. `母上 → 母さん`의 의도적 변화는 한국어에서도 보존
아주라 장면에서 시그버트는 평소 `母上`을 쓰다가 인형을 선물하려는 부분에서 의도적으로 `母さん`으로 내려간다.

따라서:
- 평소 `母上` → `어머니`
- 해당 장면의 `母さん` → **`엄마`**

문장 전체의 존댓말은 유지할 수 있다.
예:
- `엄마가 좋아할 만한 걸 노릴 테니까… 따면 받아 주시겠어요?`

핵심:
> 정발 관계 화법을 지키되, 일본어 원문이 일부러 만든 장면 한정의 친밀도 변화까지 지워 버리면 안 된다.

### 6. 부모회화의 공통 화법보다 부모 개별 캐릭터성이 우선하는 부분
시그버트는 공통적으로 존댓말을 쓰지만 어머니들의 반응은 각 정발 부모회화 모델을 따른다.

- 아주라: 차분하고 서정적.
- 펠리시아: 허둥대지만 자녀에게는 부드러운 반말.
- 모즈: 한국 정발 부모회화에서는 일본 간사이벤을 억지 사투리로 재현하지 않고 자연스러운 표준어.
- 샤를로트: 직설적이고 거친 현실주의.
- 엘피: 느리고 담백한 말투.
- 페리: 자기 이름 1인칭 + 어린 말투.
- 베르카: 짧고 절제된 반응.
- 셀레나: 츤데레식 부정과 발끈.
- 닉스: 성숙하고 차분함.
- 히노카: 군인답고 씩씩함.
- 사쿠라: 부드럽고 다정함.

### 7. 배우자 지원 콜백은 실제 정발 표현까지 맞춘다

#### 아주라 × 젠더
정발 지원에서 젠더는 아주라가 고립되지 않도록 여러 번 **회의**에 불러 주지만,
그게 아주라를 위한 배려라고는 끝까지 인정하지 않는다.

DLC의 회상도 이 구조를 그대로 잇는다.

#### 펠리시아 × 젠더
정발 지원에서 확인된 표현:
- **메이드 수련**
- **메이드복**

DLC에서 같은 사건을 회상할 때 임의로 `메이드 연습`, `하녀복` 등으로 바꾸지 않는다.

#### 페리 × 젠더
정발 지원의 핵심 말장난:
- 젠더: `그건… 네 그릇을 봤기 때문이다.`
- 페리: `그릇? 밥그릇 말이에요?`
- 젠더: `아니, 사람으로서의 그릇. 뛰어난 능력 말이다.`

따라서 DLC의 `お皿 / 食器 / 器` 혼동도 한국어에서 **접시/식기 ↔ 사람으로서의 그릇** 구조로 연결한다.

#### 베르카 × 젠더
정발 지원에서 베르카는:
- 젠더를 죽여 달라는 **의뢰를 받았지만**
- 애초에 수락했다고 답하지 않았으며
- 최종적으로 젠더를 죽이지 않았다.

따라서 DLC 회상에서:
- `암살 의뢰를 받았다` ✅
- `암살 의뢰를 수락했다` ❌

사실관계 차이는 반드시 보존한다.

### 8. 펠리시아의 부모 화법은 일본어 표면 경어에 끌려가지 않는다
일본어 DLC에서 펠리시아는 캐릭터 습관 때문에 자녀에게도 `です/ます`가 많이 보인다.
하지만 한국 정발 `시그버트_펠리시아_부모` 지원에서는 부모→시그버트가 자연스러운 반말이다.

따라서 한국어 DLC에서도:
- 일본어 `です/ます`를 보고 기계적으로 존댓말화 ❌
- 정발 한국어 부모관계에 맞춘 부드러운 반말 ✅

이는 “일본어 문법 형태보다 정발 한국어 관계 모델이 우선한다”는 원칙의 좋은 사례다.

### 9. `はわわ` 재확인
펠리시아 DLC의 `はわわっ！`도 `하와와`로 음역하지 않는다.

이번 번역:
- `으아앗!`

처럼 장면에 맞는 한국어 당황 반응으로 처리했다.
